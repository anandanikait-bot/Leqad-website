# Leqad official logo baseline — October 23, 2026

Approved: circular engineering emblem + bold "Leqad" wordmark, with Hay's Russet center (#793327), deep navy (#0E2943), ivory (#F5EFE7). The color #B74B21 remains a separate legacy CTA treatment, not the logo's official accent.

Use `leqad-official-horizontal-light-v1.svg` on cream/white backgrounds, `leqad-official-horizontal-dark-v1.svg` on navy backgrounds. Use icon-only `leqad-official-symbol-...` for app tiles, favicon, toolbar. Crop already tight and the files have no background frame. True SVG paths are digitally traced from the approved generated source, not original source vectors. Old artwork may remain in Git history for rollback but should not be active.

Favicon raster exports are included for experimentation at common sizes. Verify 16px contrast against each browser theme before production; prefer a responsive true-vector browser favicon.
